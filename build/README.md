# Build output directories

This folder holds per-platform CMake build trees. Each OS must be built on that
OS (you cannot build Linux/macOS binaries from Windows and vice versa).

- `windows/` — generated by `scripts/build-windows.ps1`
- `linux/`   — generated by `scripts/build-linux.sh`
- `macos/`   — generated by `scripts/build-macos.sh`

These directories are git-ignored; they are created on demand by the build scripts.
See the scripts in `scripts/` and docs/10-BUILD-AND-PACKAGING.md.
